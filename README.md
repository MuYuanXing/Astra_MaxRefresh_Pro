## 简介

Astra_MaxRefresh_Pro 是专为欧加（Oplus）系设备打造的高刷模块，支持原生刷新率与超频 DTBO 档位，可强制锁定所需的刷新率，无论在原生还是超频环境下，都能实现稳定高效的屏幕刷新控制。

## 功能特性

### 刷新率锁定

- 支持原生刷新率：如 60Hz、90Hz、120Hz 等
- 支持超频 DTBO：可根据需求自定义刷新率档位
- 强制锁定指定档位，避免系统自动降频或切换
- 支持按应用自动切换档位，轮询间隔可调

### WebUI 管理器

- 拟物仪表盘设计，实时显示当前档位、切换路径与帧信号
- 应用规则可从已安装应用中选择，显示应用图标
- 浅色 / 深色 / 跟随系统三种外观，动画可选完整 / 精简 / 关闭
- 边到边布局，原生适配状态栏与手势导航条

### 超频 DTBO 兼容性

- 首次启动时自动扫描全部刷新率档位，并按 120Hz 原生基准自动标注原生与超频档位，可在 WebUI 中调整
- 超频 DTBO 中必须保留 120Hz 档位，否则可能导致功能失效或不稳定
- 当自定义应用切换功能不生效时，请优先联系提供该 DTBO 的作者更新至最新版本

## 使用步骤

1. 下载并刷入 Astra_MaxRefresh_Pro 模块（KernelSU，或 Magisk + KsuWebUI）。
2. 重启设备，模块将自动扫描并标注全部刷新率档位。
3. 打开 WebUI，在「设置」页核对档位属性：超频档位需填写切换顺序，存在超频档位的分辨率需设置原生基准，然后保存。
4. 在「主页」选择全局档位并保存，或在「应用」页按应用添加档位规则。

配置文件保存在 `/data/adb/Astra_MaxRefresh_Pro_data`，卸载模块时保留，重新安装后自动恢复。运行记录位于同一目录下的 `run.log`。

## 常见问题

### 锁屏或关机重启后无法切换到高档位

- 某些设备上，超频 DTBO 在锁屏或关机重启后无法直接切换到高档位；原生用户在重启后几秒内可自动恢复到之前设定的档位。
- 建议更新超频 DTBO 至最新版本。

### 管理器推荐

- KernelSU 及其分支体验最好。
- Magisk 用户必须下载 KsuWebUI 软件，并授予 Root 权限后使用。
